# FitLog

FitLog is a workout library and workout planning web application built with Next.js. Users can browse different exercises, view workout details, save workouts for later, and create a daily workout plan.

## Technologies Used

- Next.js
- React
- Tailwind CSS
- DaisyUI
- React Toastify
- React Icons

## Features

1. Browse all workouts from an external API.
2. View detailed workout information including instructions, equipment, difficulty, sets, and reps.
3. Add workouts to Today's Plan with a maximum limit of 5 exercises.
4. Save workouts for later and manage them from the My Plan page.
5. Sort workouts by duration, calories, and rating.
6. Responsive design for mobile, tablet, and desktop devices.
7. Local storage support to preserve plan and saved workouts after page refresh.
8. Custom 404 page for invalid routes.

## Installation

Clone the repository:

```bash
git clone (https://github.com/Sayeed-sbs/fitlog.git)
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```

Open:

```txt
http://localhost:3000
```
